Featured Project

Hibi

Full-stack habit tracking application built from scratch. Users can create habits and track their weekly progress on a single page.

Key Features

  • Vue 3 SPA
  • REST API with Hono
  • PostgreSQL without ORM
  • JWT authentication
  • Password hashing with bcrypt
  • SQL queries
  • dbmate migrations
  • VPS deployment
  • NixOS configuration

Architecture

Frontend and backend are maintained in separate repositories. The application is organized into independent modules for users, habits and metrics. Each module has its own API layer and SQL queries.
